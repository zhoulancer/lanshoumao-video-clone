## 功能预览

### 视频分析
上传视频 / 图片，本地视觉模型逐帧分析，输出画面深度描述、主体细节、场景、镜头语言、光影、美术风格，并在末尾给出 **⏱️ 时间轴拆解**（第几秒画面发生了什么）。

### 音频识别
本地 Whisper 转写台词，输出**带起止时间码**的分段字幕，可与画面时间轴逐句对齐；支持同音字纠错表。

### H3 提示词转换
把分析结果 + 台词交给本地大模型，按 MiniMax H3 官方规范重写：

- **T2V 分镜脚本式**：`[0-4秒｜主题]` + `【场景细节：…】` + 镜头/动作/台词
- **I2V 三字段式**：`<Picture 1>` 首帧指令 + `integrated_multimodal_description` + `overall_soundscape` + `non_diegetic_music`

支持**音色控制**：换装/换嗓音后自动拆成 `(S1)` / `(S2)`，音色描述写在 `<d>` 外面。

### 视频生成
对接 H3 工作台（Gradio，地址在「设置」里配置，如 http://192.168.3.100:7860），提交任务后实时显示进度（13% → 88% → Save Video），完成后自动缓存到本地，链接不会失效。

### 时间轴剪辑
剪映式操作：点时间轴定位 → 标记入点 → 标记出点 → 生成保留片段；片段可**删除**、可**拖动排序**；未标记的部分自动丢弃。支持倍速、比例转换、静音、导出 MP4 / GIF / MP3。

### 字幕识别与合并
一键识别字幕 → 勾选多条**合并**、或按间隔阈值**合并相邻**碎片句 → 逐条改写 → 导出标准 SRT → 或**烧录硬字幕**压进画面。

### 历史记录
所有分析结果本地留存，支持搜索、收藏、备注、导出（TXT / MD / JSON），并可**一键转到视频生成**。

## 创作闭环流程

```
刷到喜欢的 AI 视频
         │
         ▼
  Step 1  发现灵感          刷到喜欢的 AI 视频 / 动画
         │
         ▼
  Step 2  反推提示词        上传视频 → 本地视觉模型分析 → 提示词 + 时间轴
                            本地 Whisper → 台词（带时间码）
         │
         ▼
  Step 3  二次创作          合并提示词 + 台词 → 本地大模型改写成 H3 提示词 → 人工微调
         │
         ▼
  Step 4  一键出片          提交 H3 → 进度可见 → 成片自动缓存到本地
         │
         ▼
  Step 5  后期              时间轴剪辑（删片段/拼接/变速/比例）
                            字幕识别与合并 / 烧录
```

## 功能特性

- 🎬 **视频分析**：关键帧 + 时间轴拆解，AI 自动反推提示词
- 🎙️ **音频识别**：本地 Whisper，带时间戳台词，支持纠错表
- 🤖 **H3 提示词**：T2V 分镜 / I2V 三字段，音色可指定
- 🚀 **视频生成**：本机 H3 工作台，实时进度，成片本地缓存
- ✂️ **时间轴剪辑**：标记保留片段、删除、拖动排序、变速、比例转换
- 💬 **字幕**：识别 / 合并 / 改写 / 导出 SRT / 烧录硬字幕
- 📝 **历史记录**：搜索、收藏、备注、导出，一键转生成
- 🔒 **全程本机**：不需要任何云端账号、API Key 或订阅

## 快速开始

```text
1）双击「启动_蓝手猫一键视频克隆台.bat」
   → 按配置里的地址检测 H3 是否在运行，不代你启动
   → 启动 Web（3000）并自动打开 http://localhost:3000/dashboard

2）顶部状态灯确认服务
   本程序 / H3 工作台 / 音频识别 / 本地大模型 —— 绿灯即可用

3）视频分析 → 上传视频 → 开始分析（约 1-2 分钟）

4）点结果右上角「用于视频生成」→ 自动跳到生成页并填入 H3 提示词

5）点「① 合并并转为 H3 提示词」→ 检查/修改 →「② 生成视频」
```

**关闭服务**：双击「停止_蓝手猫一键视频克隆台.bat」（只停 Web 3000，不动你的 H3）。

## 使用说明

### 视频生成参数

| 参数 | 说明 |
|---|---|
| 提示词格式 | T2V 分镜脚本（文生视频）/ I2V 三字段（首帧图生视频） |
| 生成时长 | 2-15 秒，**默认跟随原视频时长** |
| 画面比例 | 16:9 / 9:16 / 1:1 / 4:3 / 3:4，宽高自动计算 |
| 推理步数 | 8 步为日常档；4 步试提示词；20 步追求质量 |
| 音色要求 | 例如「第 4 秒换装后改用尖细阴柔的太监腔」 |

### 时间轴剪辑

```text
点时间轴任意位置 → 播放头跳转
标记入点 → 拖到结束位置 → 标记出点 → 生成橙色保留片段
片段上点 🗑 删除；拖 ⠿ 调整顺序
点「导出」→ 按顺序拼接，未标记内容自动丢弃
```

### 字幕

```text
识别字幕 → 得到带时间码的字幕列表
勾选多条 → 合并选中
或点「合并相邻」按间隔阈值合并碎片句
逐条改写文本 → 导出 SRT / 烧录到视频
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 浏览器打不开 | 看黑窗口里的地址，确认 3000 端口未被占用 |
| H3 状态灯是红的 | H3 工作台没起，或「设置」里的 H3 地址填错 |
| 音频识别是红的 | Whisper 模型未下载（首次识别会自动下载），或缺少 scripts/local-whisper.py |
| 生成很慢 | 降分辨率、步数从 8 降到 4、关闭 FlashVSR |
| 没有台词 | 先在「音频分析」对同一视频转写一次 |
| 台词识别错字 | 设置页「台词纠错」加一行 错误=正确，历史记录会同步修正 |
| 视频不显示 | 生成完成后会自动缓存到 data/storage/videos，刷新页面重试 |
